# Карман

Мобильное веб-приложение для учёта личных финансов: баланс, доходы и расходы, категории и месячные лимиты.

Данные хранятся в браузере (`localStorage`). Сервер и аккаунт не нужны.

## Что умеет

- Главный экран с общим балансом и итогами выбранного месяца
- Добавление и правка операций с категориями
- История с поиском и фильтром доход/расход
- Анализ за весь период: куда уходит больше всего денег, рекомендации и прогноз на следующий месяц
- Выбор языка и валюты при первом запуске
- Демо-данные при первом запуске, сброс на экране бюджетов

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:43123](http://127.0.0.1:43123) на телефоне или в узком окне браузера.

Сборка:

```bash
npm run build
npm start
```

## Стек
