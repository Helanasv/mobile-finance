# Достаток

Мобильное веб-приложение для учёта личных финансов: баланс, доходы и расходы, категории и месячные лимиты.

Данные хранятся в браузере (`localStorage`). Сервер и аккаунт не нужны.

## Что умеет

- Главный экран с общим балансом и итогами выбранного месяца
- Добавление и правка операций с категориями
- История с поиском, фильтром и выгрузкой CSV
- Копилка: цели и оценка срока при текущем остатке
- Повторяющиеся платежи и общий лимит расходов на месяц
- Анализ за весь период, сравнение с прошлым месяцем, рекомендации и прогноз
- Выбор языка и валюты при первом запуске
- Демо-данные при первом запуске, сброс на экране бюджетов

## Запуск

```bash
npm install
npm run dev
```

**На Mac (Safari или Chrome):** в адресной строке откройте [http://127.0.0.1:43123](http://127.0.0.1:43123). Не вводите адрес в поиск Google.

**В симуляторе iPhone:** Safari → адресная строка → `http://localhost:43123` (если пусто, попробуйте `http://127.0.0.1:43123`). На Mac должен работать `npm run dev`.

**На настоящем iPhone (тот же Wi‑Fi, что и Mac):** остановите сервер и запустите `npm run dev:lan`, затем:

```bash
ipconfig getifaddr en0
```

В Safari на телефоне откройте `http://ЭТОТ-IP:43123`, например `http://192.168.1.14:43123`. Адрес `127.0.0.1` на телефоне — это сам телефон, а не Mac, страница не откроется.

Сборка:

```bash
npm run build
npm start
```
